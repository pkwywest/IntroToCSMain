<p>Here is a short list of SOME of the tasks we can carry out with code:</p>

handful of code.</li>

decide which action to take based on data—like when the thermostat in
our house should turn the heat on or off.</li>
</ol>

<h1>3.2. Syntax Rules<a class="headerlink" href="#syntax-rules" title="Permalink to this headline">¶</a></h1>
<p>At their core, programming languages are collections of rules that allow us to
tell a computer what to do. Actions like <strong>Repeat ____ 25 times</strong>, <strong>Prompt the
user for a password</strong>, or <strong>Display text on the screen</strong> can be done with any
language. However, each one uses a different approach to complete the tasks.</p>
<p id="index-0"><strong>Syntax</strong> refers to the rules and structure of a language. For example, in
English, a sentence must begin with a capital letter and end with proper
punctuation.</p>
<p>Python and other languages can only run a program if it is <strong>syntactically
correct</strong>. Even tiny mistakes will cause a program to crash. While humans are
good at overlooking minor errors, computers cannot do the same.</p>
<p>For example, the following phrases are badly written, but humans can still
understand them. We might need to read them out loud several times, but we will
eventually get the point.</p>

<li><strong>Peas on urth</strong></li>
<li><strong>Whirled wor too</strong></li>
<li><strong>I awlyas thaut slpeling was ipmorantt</strong></li>
</ol>

<h1>3.3. Adding Comments<a class="headerlink" href="#adding-comments" title="Permalink to this headline">¶</a></h1>
<p>As programs get bigger and more complicated, they get more difficult to read.
Good programmers try to make their code understandable to others.
However, even with Python, it is still tricky to look at a large program and figure out what is going on.</p>
<p>The best coders add notes to their code to clearly explain what the program is
doing. These notes are called <strong>comments</strong>.</p>
<p>A <strong>comment</strong> is text within a program intended only for a human reader—it is
skipped when the program runs. In Python, the <code class="docutils literal notranslate"><span class="pre">#</span></code> character starts a comment,
and the rest of the line gets ignored.</p>

<h2>3.3.1. Try It!</h2>
```python.run
# This demo shows off comments!

# print("This does not print.")

print("Hello, World!") # Comments do not have to start at the beginning of a line.

# Here is how
# to make
# multi-line
# comments.

print("Comments make your code more readable by others.")

##You can use multiple symbols to make some comments stand out!
```
<p>Experiment by adding and removing comments to the code.</p>
<p>Notice that when you run the program, it still prints the phrase <code class="docutils literal notranslate"><span class="pre">Hello,</span>
<span class="pre">World</span></code>, but none of the comments appear. Also, notice the compiler ignores the blank lines left in the code.</p>
<p>Comments and blank lines make your programs much easier for humans to read. Use
them often!</p>
