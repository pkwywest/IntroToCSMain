Since the LCHS curriculum is updated regularly, new pages and assignments will be added to the Teacher Resources *after* you make your copy.

Unfortunately, moving new content from the original course into your copy is not a smooth process yet. However, you will get the hang of it after doing it a few times.

Here's a summary of how to import those new files into your own course.

## Check `LCHS Course (Teacher Resources)`

From time to time, open the **Teacher Resources** course to see if anything new has been added. A quick look at the outline on the left of the screen should let you spot new topics, pages, or assignments.

## Download All Content

1. From the *Course* button, select *Download Course Pages*.

    ![download.png](/api/files/5f2c7bed47d1fc1c1a4deae4/download.png "download.png")

1. In the window that pops up, choose the *Source Files* option.

    ![select-source-files.png](/api/files/5f2c7c1a47d1fc1c1a4deb4d/select-source-files.png "select-source-files.png")

1. Save the `.zip` file to your desktop, then double-click that file to extract it.

## Locate the New Material

1. Open the folder created from the `.zip` file. You will see subfolders for each topic in the course.

    ![course-outline.png](/api/files/5f2c808447d1fc1c1a4df68b/course-outline.png "course-outline.png")

2. Open the topic folder that contains the new material. For this example, we will use the `loops` folder.
3. You will see *markdown* (`.md`) files for all pages and assignments related to the topic.

    ![loops-folder.png](/api/files/5f2c7fc747d1fc1c1a4df47d/loops-folder.png "loops-folder.png")

4. Open the markdown file(s) in *Visual Studio Code* or other code editor.

## Add the Content to Your Course

1. Back in your copy of the LCHS course, go to the outline and add any missing topics, pages, or assignments.

    ![new-page.png](/api/files/5f2d52c547d1fc1c1a50c10c/new-page.png "new-page.png")

2. Select the new page from the side menu to open it in the workspace. Click in the workspace to open the page editor.

    ![edit-page.png](/api/files/5f2d532a47d1fc1c1a50c27c/edit-page.png "edit-page.png")

3. OK, almost there! Copy ALL of the content from the file open in VS Code and paste it into the editor.

    ![copy-paste.png](/api/files/5f2d55e947d1fc1c1a50cfb0/copy-paste.png "copy-paste.png")

4. Click "Publish" to make the page available to your students!

    ![view-page.png](/api/files/5f2d56ac47d1fc1c1a50d36d/view-page.png "view-page.png")

5. Repeat steps 1 - 4 for each new page or assignment.
